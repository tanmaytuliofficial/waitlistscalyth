# Scalyth Waitlist & Command Dashboard

Autonomous Business Intelligence & Revenue Growth Engine — Waitlist Landing Page.

## Features
- **Catalyst-Style Kinetic Hero**: Rotating headlines, dynamic problem ticker, and glassmorphism pill navigation.
- **System Awakening Particle Transition**: Dot-matrix `SCALYTH` canvas particle convergence with laser scanline sweep.
- **Conversational Waitlist Form**: Multi-step interactive flow with real-time spam toast.
- **Live Social Proof Engine**: Bottom-left rotating masked notifications (`A***n (Founder) joined the waitlist • 2m ago`) and dynamic queue counter (`10+`).
- **Command Dashboard (`/dashboard`)**: Full applicant queue with search, role filters, and CSV export (Passcode protected: `scalyth2026`).
- **Automated Dispatch**: Direct email notifications to `info@scalyth.tech` & `scalyth@gmail.com`.
